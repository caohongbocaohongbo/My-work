# 时序质检与修复

媒体可解码只是最低门槛。人物镜头必须同时验证身份、动作、空间、光照和声音连续性。

## 检查顺序

1. 完整解码、帧率、时长、分辨率、音轨和黑帧。
2. 每帧检查脸、发型、服装、身体比例、手脚和道具。
3. 检查相邻帧闪烁、纹理游走、背景变形和光照跳变。
4. 对照动作节拍检查准备、主动作、反应和收势是否真实发生。
5. 对照相邻镜头检查站位、视线、方向、持物手和情绪交接。
6. 对白镜头额外检查音画同步、错误说话人、眼神和身体节奏。

按 [修复阶梯](references/repair-ladder.md) 选择影响范围最小的修复，并保存修复前后片段与参数。

## 判定

- **通过**：可直接进入剪辑。
- **修复后通过**：问题已局部修复，未破坏身份和动作。
- **拒收重生成**：身份、肢体、主要动作或连续性错误影响核心镜头。
- **animatic-only**：只有静帧代理或低质量预演，不属于最终镜头。

不要用模糊、快速切镜、裁掉手脚或重度调色掩盖核心生成缺陷。任何自动指标都要配合代表帧和正常速度人工观看。
