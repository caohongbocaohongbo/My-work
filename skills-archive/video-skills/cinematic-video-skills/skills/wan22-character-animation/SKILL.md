# Wan2.2 人物动画

此 Skill 路由官方 Wan2.2 Animate，不携带模型权重。运行时从 `WAN22_ROOT` 或已固定版本的 ComfyUI 工作流发现，禁止向 Skill 或其他智能体配置复制模型。

## 模式选择

- **Animate**：以角色图和驱动视频生成该角色的身体动作与表情。
- **Replace**：在已有镜头中替换人物，同时尽量保留背景、构图和光照。

## 执行前检查

1. 角色圣经、参考图和动作视频已锁定且权利清楚。
2. 参考人物与目标角色在构图、身体范围和首帧姿态上可对齐。
3. 镜头时长、分辨率、帧率、开始/结束状态和交接字段齐全。
4. 固定官方仓库提交、模型版本、权重校验值和推理参数。
5. 先生成低成本测试段，检查身份、肢体、手脚、视线和背景稳定性，再跑完整镜头。

模式输入、输出和复现记录见 [Wan Animate 运行手册](references/wan-animate-runbook.md)。

## 验收

- 动作节拍必须可辨认，不能只出现呼吸或随机漂移。
- 角色身份、服装和身体比例稳定；手脚与道具交互可用。
- 背景和光照没有明显跳变，开始与结束状态可与相邻镜头衔接。
- 失败镜头先缩短动作、减少遮挡或改善参考，再调整采样；不要用平移静帧替代。

官方模型采用 Apache-2.0，但仍需遵守素材权利和适用法律。任何云端托管调用均需单独获得费用与上传授权。
