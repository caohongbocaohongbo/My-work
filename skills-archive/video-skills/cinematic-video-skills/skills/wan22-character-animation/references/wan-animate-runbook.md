# Wan Animate 运行手册

## 输入记录

- 模式：`animate` 或 `replace`。
- 角色参考、动作视频、源视频、遮罩及内容哈希。
- 镜头 ID、时长、帧率、分辨率和开始/结束状态。
- 官方仓库提交、模型名称、权重校验值和许可证版本。

## 输出记录

- 原始生成视频、逐帧序列和日志。
- 种子、采样参数、显存/设备和运行时间。
- 身份、动作、手脚、背景、闪烁和镜头交接 QC。
- 修复或重生成的原因与参数差异。

官方来源：https://github.com/Wan-Video/Wan2.2

不要使用声称是 Wan2.2 但无法追溯到官方权重或代码的镜像。模型权重不进入 Git 仓库。
