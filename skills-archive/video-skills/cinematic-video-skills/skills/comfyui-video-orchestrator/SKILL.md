# ComfyUI 视频编排

把 ComfyUI 当作可重复执行的图，而不是手工试参数的界面。优先使用官方节点；第三方节点必须固定仓库和提交版本。

## 工作流契约

1. 读取角色圣经、镜头清单与动作参考，确认输入素材有使用授权。
2. 为镜头选择最少节点链：加载模型 → 身份/姿态条件 → 采样 → 解码 → 必要修复 → 保存。
3. 保存 API 格式 workflow JSON、模型名称、权重校验值、种子、分辨率、帧数、帧率和输出路径。
4. 模型路径通过 ComfyUI 的模型路径配置或运行环境提供，不复制权重到 Skill 目录。
5. 工作流 JSON 中禁止出现 API Key、访问令牌、Cookie、用户绝对素材路径或未脱敏身份信息。
6. 生成后立即进入时序 QC；没有通过的结果只标为候选镜头。

详细的输入输出契约见 [工作流契约](references/workflow-contract.md)。

## 运行模式

- **纯本地**：禁用付费 API 节点；运行前核对可用显存、模型许可和磁盘空间。
- **自托管远端**：通过受控 API 提交已固定版本的 workflow；凭据仅从环境注入。
- **合作模型/API**：只有用户已授权该次费用和上传范围时才调用，并记录实际服务、费用口径和替代路径。

## 失败边界

- 缺少运行时、模型或显存时，输出就绪检查和待执行工作流，不把静帧代理称为最终视频。
- 第三方节点不可复现或来源不明时，不自动安装；退回官方节点或明确阻塞项。
- 不修改其他智能体的 ComfyUI 配置；每个任务使用独立的输入、输出、缓存和工作流目录。
