# 动作参考准备

用可观察的表演参考约束人物动作，不让视频模型仅凭形容词猜测复杂表演。

## 工作流

1. 把每镜拆成 2–5 个可见动作节拍，标出准备、主动作、反应和收势。
2. 确认人物在画面中的全身/半身范围、地面接触、视线目标和遮挡。
3. 优先拍摄或选择单一连续动作参考；需要跨镜衔接时保留动作前后缓冲。
4. 清理参考视频：稳定帧率、方向、裁切和时长，不改变动作节奏。
5. 记录动作素材来源、演员许可、帧率、分辨率和裁切方式。
6. 生成前先检查首帧姿态与角色参考是否能对齐。

拍摄与验收细则见 [表演参考规范](references/performance-reference.md)。

## 硬约束

- 参考视频不能含未经授权的人脸或表演素材。
- 手部、脚部和道具交互重要时必须完整可见，避免出画或长时间遮挡。
- 不在一个短镜头叠加多个冲突动作；复杂动作拆镜。
- 左右方向、持物手和视线目标必须与镜头清单一致。
- 只有嘴部音频驱动不能替代全身动作参考。
